# Helpers ディレクトリガイド

`Helpers/` は、**軽量な共通処理**を置く場所です。
テンプレートやクラスのどこからでも使える、小さな道具箱のイメージです。

## 役割

- 文字列や数値の整形
- パス組み立て
- 依存の少ない再利用処理

## このディレクトリの想定

- `Fmt.php`
  - HTML エスケープ、日付整形、文字数制限などの表示補助
- `Path.php`
  - `root/app/config/views` などのパス解決

## 書き方の目安

- 副作用を持たない（pure に寄せる）
- 例外ケース（`null` / 空文字 / 型違い）を先に考える
- 「便利だから何でも入れる」は避ける
  - 外部 I/O や重い処理は `Services` へ

## ひとこと

Helper は便利ですが増えすぎると責務がぼやけます。
迷ったら「この処理は他の層の責務では？」を先に確認する運用で OK です。
