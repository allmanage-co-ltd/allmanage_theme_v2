# Project ディレクトリガイド

`app/Project/` は案件別コードの置き場所です。
外部メンバーが主に触る唯一の PHP ディレクトリとして扱うため、細かく分けすぎません。

## ここに置くもの

- 案件固有のフック実装
- 案件固有の CSV 実装
- この案件だけで終わる使い切りロジック
- `WordPress/` や `Shared/` の基盤を使った最終調整

## 置かないもの

- テーマ全体で使う共通基盤
- WordPress 依存の共通フック
- 共通エラー窓口
- テーマ全体の Interface

## ルール

- Project の中は増やしすぎない
- 名前で案件用クラスだと分かるようにする
- 再利用できるものは `Shared/` か `WordPress/` に戻す
