# app ディレクトリガイド

`app/` は、テーマ内の PHP 実装を責務ごとに整理するための場所です。
厳密なレイヤ分離よりも、**読み手が迷わない責務分け**を優先しています。

## ざっくり構成

- `CMS/` : WordPress 依存ロジック（フック、管理画面、プラグイン連携、表示解決）
  - WordPress が提供する関数はこの中でのみ使用できます。
- `Support/` : I/O や外部依存を扱う共通サービス、汎用ユーティリティ
- `UseCase/` : ユースケース単位の実行フロー

## 最初に読む README

- `app/CMS/README.md`
- `app/Support/README.md`
- `app/UseCase/README.md`

それぞれのディレクトリで、責務と実装の温度感を合わせています。

## コーディングの共通方針（ゆるめ）

- 置き場所は「何をする処理か」で決める
- `$_SERVER` / `$_SESSION` などの直接参照は窓口クラスに寄せる
- コメントは「何を」より「なぜ」を書く
- 失敗系は握りつぶさず、呼び出し元が判断できる形にする
- 迷ったら既存実装の責務に寄せる（新ルールを増やしすぎない）

## ひとこと
