# app ディレクトリガイド

`app/` はテーマの PHP 実装を置く場所です。
このテーマでは **WordPress 依存 / 共通資産 / 案件別** を分けて、外部メンバーでも迷いにくい形を優先します。

## ディレクトリごとの役割

- `WordPress/`
  - WordPress 依存コードを置く
  - フック、管理画面、プラグイン連携、WP ラッパー、CSV 処理をまとめる
- `Shared/`
  - 今後も使い回したい共通処理を置く
  - Config / Logger / Runtime など、テーマの資産として残したいものを寄せる
- `Project/`
  - 案件別の最終実装を置く
  - 外部メンバーが主に触る唯一の PHP ディレクトリとして扱う
- `Interfaces/`
  - テーマ全体に効く最小限の契約だけを置く
- `Errors/`
  - テーマ全体で共通に使う終了系エラーの窓口を置く

## 判断基準

- WordPress 関数を直接使う処理 → `WordPress/`
- 再利用したい基盤処理 → `Shared/`
- この案件だけで使う処理 → `Project/`
- テーマ全体のルール → `Interfaces/`
- 処理を止める共通窓口 → `Errors/`

## 補足

- `Project/` は細かく分けすぎない
- `WordPress/` はディレクトリ構成と namespace を揃えて読む負担を減らす
- コメントは型情報の補足よりも「何をしているか」「なぜここに置くか」を優先する
