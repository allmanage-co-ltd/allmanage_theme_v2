# Services ディレクトリガイド

`Services/` は、**I/O や外部依存を扱う共通サービス層**です。
「どこからでも使うけど、責務は重め」の処理をここに集約します。

## 書き方の目安

- 外部 I/O はなるべくこの層に寄せる
- static API を使う場合は、呼び出し側の依存が見えづらくならない範囲で使う
- 設定値依存がある処理は `config/` とセットで追えるようにする

## 注意ポイント

- Request ごとの状態を持つクラス（Session など）は、初期化タイミングに注意
- HTTP や CSV は失敗しうる前提で、呼び出し側でもハンドリングする

## ひとこと

Service は「重複を減らす」ための層です。
逆に肥大化しすぎないよう、ユースケース固有の手順は Action 側に残すのが基本です。
