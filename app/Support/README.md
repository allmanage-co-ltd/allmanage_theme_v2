# Support ディレクトリガイド

Support/ は、アプリケーション全体で利用される
共通サービスをまとめた層です。
本当はユーティリティと基盤ロジックは分けたいのですが、
無駄に複雑にしてもアレなので一旦は簡略化。

外部 I/O（HTTP / Csv / Session など）や
アプリケーション基盤（Config / Logger など）を扱います。

ユースケース固有の処理は Usecase 側に置き、
ここには再利用可能な処理のみを配置します。

## 書き方の目安

- 特定の用途をもたない基盤や汎用性の高いロジックをまとめる
- 設定値依存がある処理は `config/` とセットで追えるようにする
